## 已验证行为

- DAG 拒绝跨项目、错误端口、缺失依赖、环路、未注册算子和测试分区拟合；布局变更不改变计算摘要。
- 并发提交只生成一个 Run；相同幂等键不同内容冲突；陈旧审批不能批准新语义。
- 真正的 PostgreSQL 行锁、租约、尝试令牌和事务发布；旧 Worker 不可续租或提交；响应丢失可以重放原回执。
- 数据库发布异常回滚后没有正式产物引用；重试能重新提交。候选等待不占租约，不被恢复任务重复投递；取消和修改版本后不能批准。
- 事件游标与状态事务一致；进度不能倒退；取消必须等执行器退出确认，不能依据租约过期声称计算已停止。
- Python 真实进程完成 split → fit → transform，输入和输出均校验内容摘要；进程不继承应用密钥。
- CSV 保留前导零、大整数编号、中文和空字符串；低频脏值与坏行阻止导入。实体/时间切分及稳定 row_id 可对账。
- 验证/测试极值不改变训练参数；未知类别不改变列数；预览转换器和不同切分版本的转换器不能混用；导出重读后标签对齐。
- 三个预置和一个自定义 Skill 源包校验；工具权限只能收窄；伪造已执行结果与不存在产物被拒绝。尚无真实模型评测或真实 Skill 发布记录；测试库中的发布仅验证合成证据控制。
