# 建模工作台体验与交互改造

## 体验范围

使用本地测试账户，通过 Codex 内置浏览器实操项目选择、数据挂载弹窗、历史任务、质量报告和任务监控。Edge 原生捕获失败，因此没有宣称操作过原 Edge 窗口。已有任务报告为 700 行、38 列；本次读取已有报告，没有将该数据重新发送给模型。测试与签收结果另见下方记录。

## 体验问题与设计决定

| 卡点 | 对建模人员的影响 | 改造 |
|---|---|---|
| 首次挂载数据时出现空监控面板 | 分不清先看哪里 | 首页默认收起右栏，通过挂载弹窗准备数据 |
| 左栏多个大按钮与项目设置挤占历史 | 历史列表过短 | 上部限制高度，下部独立滚动，搜索与分页固定在历史区域 |
| 对话逐条展示工具 JSON | 结论被执行日志淹没 | 消息区保留用户/助手文字和必要审批，工具记录移到监控 |
| 重命名、恢复与停止总是并列 | 主操作不明确 | 低频操作放会话设置，模型工作时输入区显示停止 |
| 创建任务后还需再次开始 | 用户误以为系统已在分析 | 创建会话后立即发送目标；发送失败保留会话和错误供重试 |
| 搜索只匹配名称 | 任务改名后难以按原目标找回 | 后端同时匹配名称和原始目标，保留用户/项目隔离 |
| 缩窄窗口后所有导航文字被挤入控制条 | 导航无法操作 | 遵守布局折叠状态，只显示展开入口 |

## 页面布局

左上为新建任务、数据中心、技能中心、流程模板，项目为紧凑选择器，模型设置降至底部。流程模板说明其作用：复用保存的流程，调整后仍需审批。左下是会话历史，支持搜索和分页。中间以挂载数据、描述目标、开始分析为主路径，历史会话只保留对话与必要审批。右侧由用户主动打开，使用代码、产物、上下文三个页签；代码展示真实流程定义、可折叠画布与工具记录，不虚构 Python 源码。产物展示已发布报告与下载，上下文承载输入、模型、版本及折叠执行管理。

## 实施顺序

先改前端布局、数据挂载入口、对话与监控组织，再改后端任务搜索。审批、版本冻结、发布条件与 Worker 算子规则保持原有服务端执行语义。

## 验证

前端类型构建、打包和 12 项组件数据层测试通过。后端独立 55449 测试库验证名称与目标搜索、分页和所有者隔离通过。真实 Web 快照回放通过，覆盖画布版本、审批提交、历史选择、列宽恢复、断网与新建任务/挂载数据时右栏隐藏。文档快速检查 16/16 通过，界面文案检查通过。记录保存在 `evals/data-agent/ux-redesign/`。不使用手工业务库运行清空数据的测试。

## 新任务实操

使用已有合成文件 ux-training.csv（120 行、4 列），在本地工作台依次上传并解析、指定 target 和 customer_id、挂载、填写质量检查目标、选择已注册的本地 Qwen 模型并创建任务。创建后自动进入模型处理，无需再次点击开始；诊断执行成功，产物页显示正式报告 120 行、4 列、0 重复行。空字符串默认保留为文本，因此报告的空值数为 0；这不是业务缺失值已经处理完成。本地模型随后返回三句总结，区分了空值与 income 中的空字符串。测试仅要求分析，未执行清洗或训练。历史报告查看、代码/产物/上下文切换另经手工实操。

## 任务历史与目标草稿补充（2026-09-17）

任务历史增加行内重命名与确认删除。删除仅移除用户所属会话的工作台绑定，保留数据、执行记录及审计文件；运行中的会话或处理任务拒绝删除。删除当前会话返回新任务页，搜索分页刷新后若末页为空则返回上一页。

目标区域保留示例目标，并增加可选关键词与AI生成按钮。关键词为空时直接生成，填写时按关键词生成；使用高级设置选定的模型或部署默认模型。生成过程禁用工具、记录模型输入，只返回可编辑草稿，不读取数据行、不自动创建任务。失败保留草稿并显示可理解的错误提示。

验证：前端与领域服务类型检查通过；前端构建和修改文件lint通过；独立PostgreSQL测试库的历史搜索、重命名、删除与权限保护测试2项通过；Edge真实浏览器回归通过，覆盖直接生成、关键词生成、生成失败草稿保留、重命名、取消删除、删除当前会话及原有工作台流程。模型回复在自动回归中由测试提供者返回，真实本地Qwen另行体验。

真实模型体验：本地Qwen 9B的关键词目标生成在120秒内未完成，触发超时；已将超时统一为用户可读提示并保留草稿。自动浏览器回归使用测试模型，不能作为该本地模型响应速度的证明。
