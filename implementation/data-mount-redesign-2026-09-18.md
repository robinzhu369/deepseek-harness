# 数据挂载交互调整

入口：新建任务 → 挂载数据 → 选择数据源 → 确认挂载。

- 独立弹窗显示当前项目的数据，按文件名搜索，每页 20 条；文件卡片显示名称和导入状态。
- 选中只是临时选择，确认后写入任务草稿；取消不替换数据。未完成导入的数据不可挂载。
- 上传新数据在弹窗内打开已有 CSV / Parquet 上传和字段角色配置，返回列表后选择导入完成的数据。
- 首页以文件标签展示挂载结果，点击替换或移除，保留目标草稿。
- 沿用品牌色 #0F4C9E；窄屏两列，文件区独立滚动，确认操作与列表分开。
- 当前后端没有文件夹或数据源目录，不模拟路径层级。数据中心仍保留预览、下载、归档。
