# Agent Note: 数据准备执行

Status: proposed

[English](2026-09-15-data-agent.md) | 中文

## Problem

Harness 对话循环不提供不可变数据处理、仅训练范围拟合或持久化数据作业发布。对话完成不能证明数据已符合训练要求。

## Proposal

将数据处理放在 TypeScript 领域服务中，使用 PostgreSQL 状态和 Python Polars 执行器。[开发库](../../../../extensions/data-agent/README.zh.md)验证版本、审批、租约、候选和校验发布。dsh 源码 Profile 挂载领域宿主。经过认证的 Harness 适配器提供会话身份、作用域工具和锁定 Skill；现有 React 工作区仍为后续依赖任务。

执行基础还提供显式导入/隔离规则、无状态业务算子、持久化尝试凭据摘要和宿主挂载的 Worker HTTP 处理器。Worker 凭据不接受调用方指定项目或尝试身份。真实 Python 删行测试验证影响确认前的候选隔离。

宿主将监听器、串行恢复任务和数据库连接池注册为同一个等待完成的 Cordis 副作用。启动失败传递给 dsh；销毁时先关闭在途请求，再结束连接池。回环监听和精确 Host 校验要求远程 Worker 使用内部 TLS 代理。真实 Profile 测试覆盖停滞请求和不兼容数据库版本的拒绝启动。

HTTP 监督进程将凭据保留在固定摘要的计算容器之外，记录尝试以支持重启恢复。容器网络、文件系统和 cgroup 限制通过运行内核验证。不可变上传完成后才排队导入，清理排除产物引用。Skill 发布将服务端评测证据绑定到不可变包、用例集与运行环境摘要；调用锁在默认版本变化和停用后保留历史快照。

会话适配器使用 `AgentRegistry.create/resume` 并等待作用域插件配置完成。PostgreSQL 管理用户/项目绑定与调用锁，JSONL 管理对话历史。作用域加载器仅接受这些锁，全局 Skill 或 shell 不能扩大会话能力。模型响应仍为普通已记录工具调用。真实公网 DeepSeek 测试验证诊断提交；脚本外部模型验证确定性的拒绝和进程重启回放，两者均不代表完整 Skill 质量评测。

提案与画布编辑共享乐观流程事务。不可变提案绑定证据、输入版本、参数和预期影响；认证决策与冻结 Run 提交复用同一事务辅助方法。候选决策绑定实际清单，批准在等待后再次验证对象完整性。Agent 无法通过工具集调用决策路由。

合成质量评测通过隔离、持久化的 Harness Agent，以相同任务和模型配置比较基线与候选包。提示词附带完整输出/流程 Schema。确定性 Python 校验独立覆盖冻结计算。缺少流程 Schema 导致初次开发评测无效；修正后的留出用例使用不同合成快照。合成证据无论通过率如何，均不具备业务发布资格。

业务任务将已发布上传数据集绑定到显式选定的分析、处理和特征 Run。PostgreSQL 保存不可变的前序/来源关系、执行范围和产物复用映射。任务修订号串行化分支创建、选择和取消；可重复读游标向量投影选定链路，不引入第二套事件权威。缓存准入验证字节和计算键，保留原 ArtifactVersion，并排除未发布候选。冻结重跑保留 Skill 锁，修改方案必须重新提案和审批。只有选定完整链及已验证训练导出才能认定任务完成。边界暂停保留活动计算，取消任务阻止后续阶段提交。源码 Profile 工具快照和真实 Python/HTTP 容器导出测试覆盖这些路径。

可选三列工作台通过现有布局插槽及认证 Remote 适配器连接本机领域服务。凭证仅保存在浏览器内存，界面选择与草稿按账号本地持久化。历史 Run 保持不可变，复制后的草稿需重新提案与审批。迁移 008 管理会话名称及版本化模板，界面不拥有独立执行权限。 工作台通过布局负责人恢复已保存列宽。领域会话同时限定提示词和工具，避免通用 Web 组合增加编码能力。

规划质量包含通过生产 Python 执行器运行每个有效生成 DAG。独立逐行校验识别合法值、标签、标识和派生值错误；冻结历史 DAG 检查保持独立。历史模型失败保留原始结果。评测 Agent 替换通用系统上下文，避免 Web 编码提示词和工具进入评测。合成用例不能构成人工业务验收。

CSV 空值规则先于声明的类型转换执行。显式空字符串标识生成空值，未声明的空字段保留为合法字符串。浏览器到容器的导入验证及解析器回归同时覆盖这两种情况。

上传与下载共用路由时，不能为 GET 或 HEAD 的 Fetch 请求附加流。Connection 桥接层对这两种方法采用有界无请求体路径，POST 保留流式背压。浏览器下载和按方法区分的回归验证交付行为。

容量证据将生成数据摘要、明确容器预算及实际 Web/Worker 路径绑定。独立全量逐行检查重新计算仅训练集统计量及特征值。固定规划、自动审批、缓存读取及资源采样峰值分别标明测量口径。边界失败仍记为失败；本地成功不能证明目标基础设施容量或业务发布资格。

Web 集成包遵循普通工作区发布元数据，Client 打包文件限于捆绑入口及类型声明。领域扩展保持私有。冻结需求和命令日志保留原始空白以维护摘要及测量来源；可执行源码继续接受正常空白检查。

尝试失败使用白名单结构化信封，并在容器清理前写入持久化日志。恢复保留原始分类，取消与尝试隔离仍优先。平台专用离线包包含运行依赖和固定镜像导出；不可变版本目录与显式兼容检查支持停服回退。停服快照关联 PostgreSQL、对象字节和 Harness 历史，并排除指定凭据文件。本地合成恢复不能证明目标 RPO/RTO、企业网络策略或业务批准。

引导式工作台优先展示上传、目标和提案审查，折叠技术控制并直接展示已发布质量报告。CSV 表头发现补全特征用途映射，标签与标识仍须明确指定。导入快照提供有界 Worker 失败码。Web 消息提交立即确认接收；既有 Harness 请求区间仍跟踪到空闲、持久化与销毁，并拒绝并发提交。本地 Ollama 验证通过既有可配置兼容端点及已安装 Qwen 9B 权重的 32K 上下文别名完成，不构成 Skill 业务验收。

工作台共享模型配置复用 llm-pi-ai、设置修订校验和只写凭据，不另建 LLM 客户端。任务创建解析并锁定供应商与模型身份，包括 Skill 调用元数据；地址和密钥修改继续实时生效。连通性测试使用禁用工具的合成代理会话并保留日志，通过非用户消息来源避免自动标题调用。首页配置入口仍受 Harness 连接授权保护；第一阶段有意不增加独立管理员角色。协议测试使用本地合成服务，不向公网发送欺诈数据集。

## Alternatives considered

**将对话状态作为任务数据库。** 对话取消和数据计算有不同生命周期；数据状态需要独立事务和产物引用。

**使用内存队列验收。** 此类测试不能验证租约恢复或原子游标行为。集成测试使用可丢弃的真实 PostgreSQL 实例。

**独立替代界面。** 单独的模拟应用不能验证所需的 Harness 扩展点。界面集成继续依赖经过认证的业务适配器。

## Acceptance criteria

六项 P0 要求和 54 个验收场景全部保留在[台账](../../../../implementation/acceptance.json)中。组件测试或计算压测不足以发布产品。Skill 源包在模型使用前需要实际评测与发布。

## Risks

源码扩展使用根 pnpm 锁文件，但尚未进入上游发布构建闭包。容器测试验证本地内核隔离，不构成目标基础设施验收。业务标注 Skill 评测、企业认证与目标存储/网络/恢复配置仍未提供。本地离线与恢复证据记录在 T15 报告中。对当前 Agent Note 的替代关系检索未发现需要替换的既有数据 Agent 决策。

## 对话优先的工作台

可选工作台将数据挂载留在任务主流程，监控仅按需打开。代码、产物、上下文将技术证据与对话分开；审批卡保持可见，避免必要决策被隐藏而阻断执行。搜索包含原始目标，改名后仍可找到任务。真实 Web 回归覆盖监控显隐、不可变历史、审批与布局恢复。

历史管理在侧栏提供所属用户的重命名和删除操作。删除保留执行产物和审计文件，并拒绝处理中的任务。目标生成使用独立的无工具Harness会话，记录关键词、语言及所选模型；生成文本可编辑，不自动提交任务。

模型配置增加确认删除、自动标识、折叠高级字段和保存并测试。删除复用Settings版本检查，不撤销API密钥；删除用户覆盖无法移除部署自带配置。浏览器回归覆盖保存测试、取消删除、确认删除与重新打开后的持久化状态。

建模验收增加严格数值转换与显式缺失标记替换，解决CSV导入保留字符串类型的问题；受保护字段角色仍不可修改。运行工具默认省略大体积元数据，按需读取，减少常规轮询输出而不丢弃持久化证据。真实DeepSeek测试中需要人工纠正变换节点与阶段链路；上下文溢出阻止了自主导出规划，最终经过审阅在本地完成导出。参见[验收结果](../../../../implementation/modeling-acceptance-2026-09-18.md)。

特征工程0.2.0将固定版本、MIT许可的AI-SKILLS方法融合到现有Skill ID，避免新增重复的特征规划入口。主指令保持自包含，上游原文和归属信息作为锁定资源一并传递。声明的算子依赖用于拒绝不兼容环境。包验证覆盖完整引用、不可变快照和依赖缺失；这不代表模型规划质量或业务发布资格已经通过。
