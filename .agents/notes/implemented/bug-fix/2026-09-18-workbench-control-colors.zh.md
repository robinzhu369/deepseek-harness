# Agent Note: 工作台控件配色与图标

[English](2026-09-18-workbench-control-colors.md) | 中文

Status: implemented

## 问题

面向所有后代按钮的蓝色前景覆盖让主按钮文字与蓝色背景难以区分。纯文字工具按钮也占用了监控和历史窄栏的空间。

## 决策

按钮变体负责自身前景色。监控选中态使用工作台语义选中背景、蓝色文字及明确的按下状态。导航保留共享图标与文字。紧凑工具操作保留本地化无障碍名称、悬停提示和禁用状态。

## 考虑过的替代方案

**继续添加选择器例外。** 这会保留竞争的配色规则，要求未来控件逐个排除。移除宽泛覆盖可明确变体的样式职责。

**移除所有按钮文字。** 含义不明确和具有重要后果的操作仍需要可见文字；仅常用工具操作使用纯图标。

## 影响

蓝色主题仍限定在工作台内。紧凑操作节省横向空间，但不熟悉图标的视觉用户需要依赖悬停提示。组件快照覆盖监控选中状态与图标操作的无障碍属性；完整的登录后视觉检查仍需要已登录浏览器。
