## Use this package

在 Web profile 之后加载[源码覆盖层](../../../deploy/data-agent/workbench.source.patch.yml)，明确配置领域服务与回环地址。默认 Web profile 不启用本插件。

Host 控制器必须配置 `pollIntervalMs`（至少 1000）和 `maxUploadBytes`（正整数）。浏览器凭证仅保存在内存，刷新后需重新连接；界面选择与流程草稿按账号保存在本地。


## Understand the implementation

三列共享注册的界面状态仓库，领域模型不依赖 React，通过框架钩子注入。读取结果按账号和请求代次隔离。历史 Run 快照只读，复制会创建独立流程身份；修改后的保存或提案不继承审批。

首页以淡网格衬托居中的目标输入区，工具栏内提供数据挂载与选择。快捷任务只填入目标，不直接提交；AI 目标生成和高级设置默认折叠。侧栏按图标文字导航、项目选择与任务历史组织，仅在需要时显示分页。创建任务仍须选择就绪数据集并填写目标。CSV 导入从最多 64 KiB 的前缀发现完整且唯一的表头；未指定用途的列作为特征，标签与标识列仍由用户明确指定。未在高级选项中声明类型时保留文本。Parquet 与无表头 CSV 需要在高级设置填写完整用途。导入失败显示 Worker 错误码；就绪的数据可直接创建任务。工具详情与执行管理默认折叠，已发布质量报告直接展示行列数、重复行与字段统计。消息提交立即确认接收，权威历史持续更新。数据中心支持分片校验续传、不可变导入及有界预览任务。Skill 操作遵守后端生命周期门禁；停止模型回复、取消 Run、取消业务任务是三个独立操作。


Skill 阶段入口展示默认版本与最近评测；选定版本会创建新的规划会话，仍须审查具体提案。草稿证据可保留原提案的已发布引用。拖动既有分隔线后点击保存列宽，可在刷新后恢复布局。

导航采用共享线性图标与本地化文字。搜索、发送、历史编辑和监控标题栏的紧凑操作提供本地化无障碍名称与悬停提示。监控选中态使用工作台选中背景令牌；按钮前景色由各自变体负责。

### 开发备注

不发布运行时 invariant 配套模块：本消费者没有需要对账的独立持久执行状态；模型竞态测试、图校验与真实 Web 装配回归负责验证。

## Model Experience

### Domain interaction

#### What the model sees

本包不直接提供模型内容。本包呈现或转发 `/v1/data/` 请求；领域 Harness 集成负责模型上下文和工具执行。

#### Token effect

本包不增加 token。显式提交的会话消息由领域集成渲染。

#### KV Cache effect

没有直接影响。提交的消息通过既有负责人扩展底层对话。

## Known Limitations and Deferred Work

- 界面轮询权威快照，读取失败时显示待同步。冷会话需显式恢复。导航最多返回 200 个 Run 与提案，事件界面展示已加载记录的最近 200 条。上传哈希计算会缓冲不超过配置限制的单个文件；高级算子参数和 Skill 包使用 JSON 编辑器。

首页在“连接工作台”下方提供共享模型配置入口，业务登录前即可打开。每个命名模型配置通过既有 llm-pi-ai 设置命名空间保存兼容 Chat Completions 的官方、中转或自部署地址、只写凭据引用、思考协议与强度、上下文容量、输出上限和超时。保存带修订校验；不回读密钥，编辑时留空保留原密钥。连通性测试提交不带工具的合成 Harness 请求并返回安全状态，不代表业务质量通过。新任务可选择已注册的供应商和模型；已有任务保留模型身份，共享地址与凭据的后续修改仍会生效。第一阶段不区分管理员与用户权限。

工作台默认收起监控。导航分别为常用操作与可搜索、分页的历史记录预留空间。对话展示消息和审批卡；代码页签包含流程定义与工具记录，产物包含报告和下载，上下文包含输入、模型、版本和执行控制。创建任务后立即发送目标；发送失败保留会话供重试。模板复用流程但不携带审批。会话搜索同时匹配名称与原始目标。

任务历史支持直接重命名和确认删除。删除仅移除所属用户的历史入口，保留数据集、执行产物和审计日志；运行中的会话或处理任务禁止删除。新任务目标支持示例填入、AI直接生成和按关键词生成，使用当前选择的模型。生成过程通过禁用工具并保留日志的Harness会话完成，不创建业务任务、不读取数据行；生成失败保留已有草稿。

模型弹窗自动生成配置标识，高级参数默认折叠，新建本地Ollama配置可留空密钥，并支持一键保存并测试。确认删除通过带版本检查的Settings修改移除一条工作台模型配置；历史和凭证引用保留，依赖该配置的任务无法继续调用。若配置由部署提供，移除用户覆盖后仍存在，会明确提示。新任务所选模型被删除后清除该选择。
